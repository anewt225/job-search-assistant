# Report Template

Two outputs: a short in-chat summary, and a full written report saved as
`LinkedIn_Assessment_[Name]_[YYYY-MM-DD].md`.

---

## In-chat summary

Keep it short. The full report carries the detail.

```

**[NN]/100 · [Grade]**

| Dimension | Score | |
|---|---:|---|
| A. Discoverability | 24.2 / 32 | ███████░░░ |
| B. Relevance & Semantic Depth | 5.8 / 26 | ██░░░░░░░░ |

**Working:** [2–3 items — lead here, people cut good sections when they panic]

**The three that matter:**
1. [Action] — `[N] min` → **+[N] pts** ([criterion])
2. [Action] — `[N] min` → **+[N] pts** ([criterion])

```

Then ask which they want next: the rewrites, or the importable task list.

## Full report

### 1. Header
Name, target role, target locations, target companies, headline posture used, date,
sources supplied, sections **not assessed**.

### 2. Composite
Score, grade, and a one-paragraph plain-language read. Name the binding constraint — the
one dimension holding the score down — rather than listing everything wrong.

### 3. Dimension tables
One table per dimension:

| Criterion | Score | Weight | Earned | Reasoning |
|---|:-:|-:|-:|---|
| A1. Headline: target job title | 3/4 | 10 | 7.5 | [one sentence] |

### 4. Keyword gap
The three-bucket table from the harvest.

| 🔴 Missing | 🟡 Tags only | 🟢 In prose |
|---|---|---|

Then the reach columns and the 50% Rule read: *"You currently substantiate roughly N% of
stated requirements, which puts you [at / below / above] the range that converts best."*

### 4b. Advisory Panel
Seven verdicts per `advisory-panel.md`, then **where the panel splits** and **what they're all
circling**. Unscored. Keep each verdict to 2-4 sentences and make every one quote actual profile
text - a verdict that could apply to any profile is padding.

### 5. Section-by-section
For each profile section: what's there, what's wrong, what to do. This is the part users
actually work from — be concrete. No "consider strengthening"; say what to write.

### 6. Peer comparison
Peer headline patterns verbatim, what peers say that the user doesn't, and — the important
half — **what the user can say that peers can't.**

### 7. Action plan

Every task must be **independently executable** - readable months later by someone with no memory of this conversation. That means each carries its own WHY (the criterion and the reasoning), not just a verb.


| # | Action | Criterion | Points | Min | Pts/min | Priority |
|---|---|---|-:|-:|-:|---|

Sorted by criticality, then points per minute. Include the projected composite after the
top three, and an explicit **stop rule**.

### 8. Contested calls
Where sources disagreed, which way you scored, and why. Headline posture always appears
here. This section is what makes the assessment arguable rather than oracular — keep it.

### 9. Sources
Link `sources.md`. Note anything scored against 2026 platform behavior that contradicts
published book guidance.

## Rules

- **Never round the composite up.** 79.4 is a B, not a B+.
- **Never inflate to be kind.** Deliver a low score kindly; don't hide it.
- **Every recommendation cites its criterion.** Users should be able to disagree with the
  rubric, not just with you.
- **Distinguish "scored 0" from "not assessed."** Missing input is not a failing profile.
- **Lead with what works.** Then the gaps.
- **Give one stop rule.** Profile work expands to fill available anxiety. Name the point at
  which they should close the laptop and go talk to a human — that is what the profile is
  for.
