# Event Prep

Input: an event link, screenshot, calendar invite, confirmation email, or a description — plus anything
the user wants to add (goal, who's going, how much time they have).

## Step 1 — Ask once, up front (one message, multiple choice)
1. **Outputs** (multi-select, default = all that their connected tools support):
   a) Networking brief (file) · b) Calendar events per session, each carrying the brief summary ·
   c) Debrief doc + a 20-min calendar block the next morning · d) Follow-up tasks in their task tool
2. **Goal** for this event (pick): job-search conversations · community/visibility · learning · content · bridge/freelance work
3. Anything they already know (ticket type, who's attending, colleagues going)?
Skip any question the input already answers.

## Step 2 — Mode
- **Light** (≤3 hours AND no published agenda — happy hours, meetups): brief §0, 1, 3, 5, 6, 9 only; one calendar event.
- **Full** (2+ sessions or named speakers — conferences): everything below.

## Step 3 — Workflow
**A. Intake & reality check** — fetch the event page (if it renders empty, try a browser tool or ask for
a screenshot). If email is connected, search for the confirmation: **the ticket decides what you can
attend** (an "expo pass" ≠ sessions/receptions — never assume full access). Check the calendar for
conflicts and how many other events are that week; flag a 3rd event in one week.

**B. Agenda** — every session: time, title, type, room, speakers + orgs, description (verbatim). Parallel
breakouts → one PICK, rest alternates. Names not published → say so; never guess.

**C. Fit check** — one honest paragraph: who's in the room vs. the user's targets (profile §1); job-search
value, community value, time cost. Recommend **attend / partial / skip**. Name the positioning frame
(practitioner · job seeker · consultant) and any house rules (e.g. no job hunting, no "suitcasing" on expo floors).

**D. Prioritise sessions** — MUST / HIGH / MEDIUM / LOW / SKIP:
| Signal | Usually |
|---|---|
| Unstructured time (breakfast, breaks, receptions) — where conversations happen | MUST/HIGH |
| Speakers/attendees from target companies or target roles | HIGH |
| Interactive formats where they can *show* a strength | HIGH–MUST |
| Content reusable for a LinkedIn post / positioning | +1 tier |
| Generic keynote, no named speaker | LOW |
| Outside their lane | SKIP |
| Not on their pass | Free (state why) |

**E. People** — speakers, moderators, organisers, sponsors. Tier with Golden 20 (helpfulness ×
influence). Tier 1–2 only: 1–2 web searches each → role, why they matter, one hook question, link. Cross-check
the data store (already a contact?) and a LinkedIn Connections export if provided (filter with code — never
read a big CSV inline). Email lookups (Hunter/Apollo) for Tier 1–2 only and only if no public address; report
confidence. Mark guesses INFERRED.

**F. Brief** (write before the calendar so events can link to it) — template below. Save as
`<networking folder>/YYYY-MM-DD Event Name/Event-Name_Brief.<fmt>` (profile §4/§6). For Drive, keep `.md`
unconverted.

**G. Calendar** (if chosen) — on the job-search calendar from profile §4, explicit time zone:
- Title `<SHORT>: <Session>`; breakouts `(PICK)` / `(alt)`.
- Busy = MUST/HIGH/MEDIUM; Free = LOW/SKIP/alternates/not-on-pass.
- Colour (Google): red MUST · orange HIGH · yellow MEDIUM · graphite Free.
- Description: first line = link to the brief; Busy events add the **Brief at a glance** block (≤900 chars),
  then priority, why, do/watch-for, verbatim session details.
- Read back and verify count, Busy/Free split, links. Duplicate umbrella events (auto-added from email
  or created by the user) → ask before moving to trash; never delete permanently.

**H. Follow-up scaffolding** (if chosen) — flat tasks (no subtasks): same night "log people met"; +1 day
LinkedIn notes/thank-yous; +2 days promised items; +7 days call requests; +30 days update note. Contacts
convention: Notes = `Met at: <Event> (<date>)`.

**I. Debrief** (if chosen) — create `Event-Name_Debrief.<fmt>` from the template below + a 20-min block
next morning titled `Debrief: <Event>` linking to it. When the user returns with notes/voice memo: create
or update Contacts, log a Meeting (Type = Event, Live = true per real conversation), draft the follow-ups
(networking outreach rules apply, ≤3 at once), and report conversion: conversations · follow-ups sent ·
calls booked.

## Stop rules
Prep time box: single session ≤30 min · full day ≤60–90 min · multi-day ≤2 h. **The brief is the prep.**
Research Tier 1–2 only. One give-first offer per event, scoped to 2–4 hours. Success = calls booked
within 10 days, not cards collected. If the fit check says low value, say so.

---

## Brief template (scale down for light mode)
```
# <Event> — Networking Brief
_Prepared <date>. Self-contained._

0. The one-paragraph version — what the room is, the mission, the numeric target (e.g. 4 real conversations, 2 calls booked)
1. Event facts — date/time, venue + entrance, getting there, ticket/pass + what it covers, food, house rules, organisers
2. What it is / isn't — honest fit + time check
3. Positioning — badge line · 30-sec intro tuned to this room · 10-sec version · "what are you doing now?" answer · 2–3 CAR proof points that fit the room
4. Day plan — table: time | session | priority | my move
5. People — Tier 1 / 2 / 3 tables: name, role, why, hook question, link
6. Conversation playbook — openers better than "what do you do?", TIARA questions tuned to the room, a give (60 seconds of value), exit line, ask ladder (advice → intro; stop there at events)
7. Give-first move (optional) — offer, why, limits
8. Content plan (optional) — one post, angle, deadline
9. Follow-up plan — dated steps + success metric
10. Open items
11. Sources
```

## Brief at a glance (calendar description block)
```
📄 BRIEF: <link>
• Mission: <N conversations · give-first · calls booked by <date>>
• Intro: "<30-sec intro>"
• Tier 1: <names (org)>   • Tier 2: <names (org)>
• Ask: "<q1>" · "<q2>" · "<q3>"
• Rules: <frame · house rules · pass limits · logistics gotcha>
• Tonight: log people met + LinkedIn notes within 24h
```

## Debrief template
```
# <Event> — Debrief (<date>)
| Person | Org | What we talked about | Promised | Follow-up by | Booked? |
What worked / what I'd change (3 lines) · Conversations: N · Calls booked: N · Next event worth it? Y/N
```
