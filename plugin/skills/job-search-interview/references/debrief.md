# Interview Debrief

## 1. Get the content (accept any of these)
| Input | How to handle it |
|---|---|
| Meeting tool (Fireflies, Granola, Otter, tl;dv) | Search by date and company or attendee and fetch the transcript. Keep timestamps for linking |
| Meet/Zoom/Teams transcript, Drive doc, file | Read it |
| Audio/video upload | Transcribe if a tool is available; otherwise ask for a transcript |
| Notes or summary only | Use them, and flag that the per-answer assessment is lighter |
| Nothing: "let me talk you through it" | Interview them: who was there → what they asked (one at a time) → what you said → how it ended → any signals. Build a reconstructed Q&A from that |

From the content, extract: interviewer(s) and roles, questions asked (in order), a summary of each
answer, the user's own questions, signals of interest, next steps and timeline mentioned, and any
names, numbers or initiatives to reference later.

## 2. Self-assessment comes first, before your analysis
Ask 3 quick questions in one message:
1. Gut rating, 1–5?
2. Which answer felt strongest, and which felt weakest?
3. Want this job? (hell yes · probably · need more info · no)
Collecting this before giving any feedback keeps the reflection honest and makes the comparison useful.

## 3. Assess
- **Per answer:** framework fit (FIT for TMAY, RAC for "why", CAR/SCAR for behavioural, structure for a
  case), roughly 2 minutes or less, the strength, and the fix.
- **Overall:** fill in `interview-scorecard.md`, compare your rating with theirs, and explain any gap of
  2 or more.
- **Patterns:** if earlier debriefs exist in the interview prep folder or the Meetings table, note any
  issue that recurs (e.g. "TMAY ran long in 3 of the last 4"). Keep a running list in the scorecard's
  "My patterns" section.

## 4. Thank-you draft (send within 24 hours)
150–250 words, one per interviewer, each different:
gratitude (one sentence) → **a specific moment they said** → how your experience connects to it → one line
reinforcing your candidacy → a follow-up signal ("I'll check in by <date> if I haven't heard"). Write it in
the user's voice, without corporate filler. Create an email draft only if the user asks and email is
connected.

## 5. Update the systems (show the list first, then write)
- **Meeting:** Status → Done (Thank-you sent once it's sent), Self-rating, notes/transcript link, Lessons
  learned (the summary), Next steps.
- **Opportunity:** Status (e.g. Screening → Interviewing), Next Step and Next Step Date.
- **Contact (interviewer):** create or update, Last Contact = today, Status = Talked, Notes = hooks for
  later.
- **Tasks (flat):** send thank-you (today) · follow up if no reply (the date they gave + 2 business days,
  or +7 days) · prep for the next round if signalled · one practice task targeting the ONE thing to
  improve.

## 6. Save
`<interview prep folder>/<Company>/<Role>/YYYY-MM-DD_<Stage>_Debrief.<fmt>` containing: key takeaways ·
questions they asked (with timestamps or links if available) · their signals · next steps · self vs.
assessed rating · lessons learned · intel for the next round.
