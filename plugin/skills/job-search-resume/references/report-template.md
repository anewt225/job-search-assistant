# Report Templates

## In-Chat Summary Format (Resume)

Use this format for the in-chat summary after scoring a resume:

```
## Resume Assessment: [Name] → [Company] [Role]

**Composite Score: [XX]/100** — [one-line verdict]

| Dimension | Score | Notes |
|-----------|-------|-------|
| Contact Info | X/10 | [brief note] |
| Summary | X/10 | [brief note] |
| Experience | X/10 | [brief note] |
| Education | X/10 | [brief note] |
| Certifications | X/10 | [brief note] |
| Skills / Additional | X/10 | [brief note] |
| Formatting & ATS | X/10 | [brief note] |
| Visual Balance | X/10 | [brief note] |
| GLORY Score | X/10 | [brief note] |

| JD Alignment | Score |
|-------------|-------|
| Requirements Match | XX% |
| Responsibilities Match | XX% |
| Keyword Match | XX% |
| **JD Fit Average** | **XX%** |

**50% Rule**: You meet ~XX% of stated requirements. [verdict]

**Top 3 Strengths**: [list]
**Top 3 Gaps**: [list]
**#1 Priority Action**: [single most impactful thing to fix]
```

## Full Report Format (Saved to .md file)

The full report (saved to the applications folder from the profile) should follow this exact structure:

```markdown
# [Document Type] Assessment: [Name] → [Company] [Role] ([Req ID if available])

**Date:** [YYYY-MM-DD]
**Overall Score: [XX]/100** — [one-line verdict]

---

## PART 1: [RESUME SECTION / COVER LETTER SECTION] SCORES

### 1. [Dimension Name] — [X]/10 [emoji: ⚠️ if ≤3, nothing if 4-7, ✅ if ≥8]

**What's working:** [specific strengths observed]

**What needs work:** [specific gaps identified]

**Recommendations:** [actionable, specific fixes]

[Repeat for each dimension]

---

## PART 2: JD ALIGNMENT SCORING

### Requirements Match

| Requirement | Score | Evidence | Gap |
|------------|-------|----------|-----|
| [Each JD requirement] | [emoji + X/10] | [what the document shows] | [what's missing] |

### Responsibilities Match

|---------------|-------|----------|-----|
| [Each JD responsibility] | [emoji + X/10] | [what the document shows] | [what's missing] |

**Responsibilities Match Score: XX/110 (XX%)**

---

## PART 3: KEYWORD GAP ANALYSIS

**Keyword Match Rate: XX%** (X/Y key concepts found)

### Critical Missing Keywords (add immediately):
```

## Before/After Comparison Format (Tailor mode)

When showing before and after scores:

```
## Assessment Delta: [Company] [Role]

| Dimension | Before | After | Δ |
|-----------|--------|-------|---|
| [Each dimension] | X/10 | X/10 | +X |
| ... | ... | ... | ... |
| **Composite** | **XX/100** | **XX/100** | **+XX** |

**Keywords Added**: [list of keywords that were missing before and now present]
**Remaining Gaps**: [any critical gaps still unaddressed]
```
