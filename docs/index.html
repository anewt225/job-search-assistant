A job-search assistant that runs in the AI you already use.

Eight small skills that cover the whole search, from figuring out what to target to negotiating the offer. Each one is built on proven playbooks (The 2-Hour Job Search, Never Search Alone, Reverse the Search, Linked, The Job Closer), wired to whatever tools you already use, and tuned to the kind of coach you want.

Works in Claude · ChatGPT · Gemini · Grok · Codex · Claude Code · Antigravity · any app that reads Agent Skills

Get started

Three steps, about five minutes

  1. Install in your AI app. Pick it below for the exact steps.
  2. Set up by saying "set up my job search": 5 short steps, one question at a time (or use the optional wizard below). Either way you get one small job-search-profile.md that every module reads. In a hurry? Skip it and ask for what you need.
  3. Use it. "Draft outreach to…", "Prep me for my interview with…", "Score my LinkedIn for…"

FAQ

Which AI apps does it work in?

Any app that reads Agent Skills, the open SKILL.md format: Claude, ChatGPT, Gemini, Grok, Codex, Claude Code and Antigravity, plus others such as GitHub Copilot and Cursor. The skills never assume which app they're in. App-specific steps live in one table (hosts.md).

What does it cost?

The skills are free. They run on your existing AI plan (Claude Pro or higher; a ChatGPT workspace with Skills turned on; any Gemini or Grok account; or Codex). Connectors and big imports use more of your usage. The Notion template is the cheapest way to set up.

Will it send emails for me?

No. It only drafts. It never sends messages and never guesses email addresses.

Do I need any connectors?

No. Every module falls back to paste or upload. Connectors just save you copy-pasting.

Where is my data?

Only in your own AI account and your own tools. This page stores nothing on a server; your answers stay in your browser.
